One command. Your infrastructure.

Install the CLI, configure your providers, and check local readiness.

curl -fsSL https://getswarmforge.tech/install | bash

Requires Linux x64 with glibc and configured VM/model providers. Inspect the script.

FROM ASSIGNMENT TO HANDOFF

A clear path through
parallel work.

Agents get room to work. You get the controls to understand what happened.

01 / ASSIGN

Give the task a home.

Queue a worker through MCP with its task, instructions, timeout, and expected deliverables. Each worker runs in an isolated VM.

02 / OBSERVE

See work as it moves.

Inspect response activity, results, reported test outcomes, and measured token usage. Find workers with dashboard search and filters.

03 / COLLECT

Keep what matters.

Preserve artifacts, download them with checksum verification, inspect Git handoffs, and clean up eligible retained VMs.
